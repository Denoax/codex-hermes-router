# Showcase art direction

The canonical `assets/codex-x-hermes.png` hero is the supplied source asset and
must remain byte-for-byte unchanged.

Supporting technical visuals use a monochrome editorial language:

- black, white, and neutral gray;
- large negative space and terse copy;
- real runtime evidence;
- plain, inspectable SVG source;
- no gradients, glow, 3D, generated illustration, or synthetic product UI.

Runtime proof belongs in normal text or code blocks captured from the tool. New
benchmark visuals require reproducible benchmark data first.
